# Forecast Snapshot API Contract

This API is read-only and serves the latest approved forecast snapshot generated by `analysis/predict_2027_2029.py`.

## Base URL

- Local: `http://localhost:8000`

## Endpoints

- `GET /health`
  - Returns service status.

- `GET /v1/snapshots/latest`
  - Returns metadata about the latest approved forecast run.
  - Response fields:
    - `pipeline_name`
    - `latest_run_id`
    - `latest_run_dir`
    - `updated_at`

- `GET /v1/forecast/model1?limit=200&min_probability=0.0`
  - Returns model1 forecast rows sorted by `predicted_sla_breach_prob` desc.
  - Query params:
    - `limit` (1-5000)
    - `min_probability` (0.0-1.0)

- `GET /v1/forecast/model2?limit=200&min_probability=0.0`
  - Returns model2 forecast rows sorted by `predicted_hotspot_prob` desc.
  - Query params:
    - `limit` (1-5000)
    - `min_probability` (0.0-1.0)

- `GET /v1/forecast/summary`
  - Returns aggregated snapshot KPIs for model1 and model2.

## Publish Contract

The API reads `data/artifacts/latest/forecast.json` as the single source of truth pointer.

The referenced run directory must include:
- `forecast_model1_2027_2029.csv`
- `forecast_model2_2027_2029.csv`
- `run_metadata.json`

If the pointer is missing or files are absent, API responds with non-200 errors.

## Run API

```bash
source .venv/bin/activate
uvicorn api.app:app --reload --port 8000
```
